# Student Grades Management System (v3.0) 🎓

An updated and enhanced C++ console application designed to manage, search, sort, and analyze student records efficiently.

---

## 🚀 Features

- **Add & Display Records:** Store student details including ID, Name, and Grade with proper buffer management for full names.
- **Grade Ranking:** Sort students in descending order based on their grades and display their class ranks.
- **Linear Search:** Search for students by name with a step-by-step comparison counter.
- **Binary Search:** Efficiently locate students by ID using $O(\log n)$ Binary Search.
- **Statistical Analysis:** Instantly compute class statistics including the highest grade, lowest grade, and overall average.

---

## 🛠️ Built With

* **Language:** C++
* **Standard Library:** `<iostream>`, `<vector>`, `<string>`, `<algorithm>`
